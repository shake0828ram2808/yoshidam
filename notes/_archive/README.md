# 退避した記事

連載の方針を変えたときに、いったん外した下書き。記事の一覧(`notes/articles.js`)には載せていないので、
どこからもリンクされない。使うときは `notes/<連載>/` に戻し、`articles.js` に1件足す。

- `react-vue/overview` … Vue と React の概要(生まれ・バージョン・使われ方)。一部は「はじめに」に移した
- `react-vue/react-basics` … React の基礎(最低限の構成と、必要に応じて足すもの)
- `react-vue/reactivity` … 画面の更新の仕組み(リアクティブと再実行)
