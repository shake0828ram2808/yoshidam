# よしだ | エンジニアポートフォリオ

ビルド不要の静的サイト(HTML / CSS / JavaScript)です。GitHub Pages や Cloudflare Pages にそのまま置けます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体 |
| `styles.css` | 見た目・アニメーション(色などは先頭の `:root` に集約) |
| `script.js` | 動き(現在地ナビ・時間が進む空・スクロール演出・カウントアップ・キャラの反応) |
| `game.js` | 遊びの要素(実績・かくれた どんぐり5個・探索度・冒険の記録パネル) |
| `sound.js` | 効果音(はじめはオフ。WebAudio で合成し、音声ファイルは使わない) |
| `404.html` | ページが見つからないとき(迷子のだんごむし) |
| `assets/images/characters/` | キャラクター素材(だんごむしは nigerun リポジトリから流用。`piko/` はピコ3色のふつう顔・にっこり顔) |
| `assets/images/projects/` | 各アプリの画面(スマホ枠の中に表示) |
| `assets/images/og-image.png` | SNSで共有したときのカード画像(1200×630) |

## Focus セクション(旧 How I Build)

「気をつけている考え方」と「AI駆動開発の実践」(サイクル・設計の工夫・開発ログ)の2つのまとまり。スマホでは実践の3つを折りたたみにする。

- **3つの問い**(本当にわかりやすいか / 何を作り何を作らないか / 未来で困らないか)は、ヒーローの「工夫・効率・持続性」の順。自己PRの④UX・①要件定義・②保守性に対応させている。
- **AI駆動開発のサイクル**(5段)は、画面に入っている間 1.8秒ごとに順に光る。
- **設計の見どころ**は、アプリごとのタブ。コードは各リポジトリからの実際の抜粋で、簡単な色分けを JS でかけている。
  数字(頭痛手帳のテスト 18ファイル・143件)は zutsurun の `npm test`(コミット 0e10635 時点)の結果。
- **開発ログ**は nigerun の CLAUDE.md / docs/PLAN.md の変更履歴から節目を選んだもの。新しい節目は `index.html` の `.log-track` に `li` を足す。

## 仮のままの場所を確認する

仮のデータが入っている要素には `data-todo="何を入れるか"` が付いています。

- ページのURLに **`?todo`** を付けて開くと、仮の場所が点線の枠で囲まれ、何を入れるかのラベルが出ます。
  ブラウザのコンソールにも一覧が出ます。
- 数字(ヒーローの実績・Works の Before/After)は、本番でも小さく「仮」と表示されます。
  実際の値に差し替えたら、その要素の `data-todo` を消してください。

## 公開先

- Cloudflare Pages(ビルドなし・出力ディレクトリはリポジトリのルート)。ワーカーは使わない
- `index.html` の `og:url` と `og:image` は、公開URLの絶対パスで書く(URLが変わったら差し替える)
- `404.html` はサイトのルートに置かれる前提で `/assets/...` を参照しています

## 遊びの要素(game.js)

- **かくれた どんぐり**: About(ヒーロー) / Skills / 子ども向けゾーン / Cast / Focus に1つずつ(Cast のものは保存データの都合で id が `notes` のまま)。
  PCはカーソルを近づけると光り、スマホはうっすら見えて ときどき揺れる。5つ集めると Contact に「このサイトの仕掛け」が出る。
- **実績**: `game.js` 先頭の `ACHIEVEMENTS` に一覧。`secret: true` は解除するまで名前を伏せる。
- **探索度**: 訪れたセクション 50% + 実績 30% + どんぐり 20%。ヘッダーの丸いゲージに表示。
- 記録は `localStorage`(キー `yoshidam:quest:v1`)だけに保存。冒険の記録パネルの「記録を消す」で初期化できる。

## 空の動き(script.js)

- スクロールで決まるのは「目標の時刻(0〜1)」だけ。表示は `SKY_FOLLOW_MS` の速さで目標へ なめらかに追いつく。
- 月と太陽は別の要素(`#skyMoon` / `#skySun`)。どちらも画面の外まで出てから消えるので、入れ替わりで位置が飛ばない。
- 目印の位置は毎フレーム測らず、`measureSkyAnchors()` で覚えておく(大きさが変わったら測り直す)。

## スマホの読みやすさ(script.js / styles.css)

- **下のナビ**(`#sectionDock`, 900px以下): セクションのチップを横に並べ、今いる場所を色で示して真ん中へすべらせる。
  「次へ ○○」(`#dockNext`)は、下のナビのすぐ上・右端に浮かぶボタンで、次のセクションへ移動(最後は「先頭へ」)。
- **折りたたみ**(760px以下): `data-fold="ボタンの文言"` を付けた要素は、JS が「開閉ボタン + 中身」に包む。
  zutsurun の ExpandRow と同じ手ざわり(行のどこを押しても開閉、丸ボタンは1秒で1回転して ⌄⇔✕、高さは0.36秒でなめらかに)。
  PCでは折りたたまず、いつも全部見せる。ボタンの下の小さな要約は `foldSummary()` で作る。
- 「自分が便利なアプリ」「子どもと楽しむアプリ」「Cast」は、スマホでは横スワイプ(前後ボタン・ドット・枚数つき。共通の `setupCarousel`)。アプリのカードは「上に小さな画面+名前、下に説明」の形。
- About の Career・Skills・Certs は、スマホでは折りたたみ(勝手に開く動きは入れない)。

## メニューの構成

About・Apps・Cast・Focus・Contact(ヘッダー・右端のドット・スマホの下のナビで共通)。Notes は note の記事を公開するまで `hidden`(外せば戻る)。
- About(01)は、ヒーロー・経歴(`#about`)・スキル(`#skills`)・資格(`#certifications`)のまとまり。これらの section には `data-group="hero"` を付け、
  メニューでは About の一部として扱う。
- Works(業務での工夫)は note の記事を書いてから戻す予定。HTML は git の履歴(コミット 08ff222 まで)に残っている。
